- README 或 `docs/deploy/docker.md` 有 5 行以内的启动说明

**涉及文件**：`docker-compose.yml`（新）、`.dockerignore`（新）、`docs/deploy/docker.md`（新）

## 2. 环境变量覆盖配置

**标签**：`enhancement` `good first issue`
**难度**：小

**背景**
容器里不方便改 YAML，需要用环境变量覆盖 `.coderev.yml`。

**做什么**
- `CODEREV_PROVIDER` / `CODEREV_MODEL` / `CODEREV_BASE_URL` / `CODEREV_RULES` / `CODEREV_MIN_CONFIDENCE` / `CODEREV_MAX_FINDINGS`
- 优先级：命令行 > 环境变量 > `.coderev.yml` > 默认值

**验收**
- 只设环境变量、不传命令行参数，也能跑通 `coderev review`
- 补测试：环境变量覆盖 YAML、命令行覆盖环境变量

**涉及文件**：`src/coderev/config.py`、`src/coderev/cli.py`、`tests/test_config.py`

## 3. 常驻 webhook 服务

**标签**：`enhancement` `help wanted`
**难度**：大（3–5 天）

**背景**
Action 只能在 PR 事件时跑；自托管服务需要接收 GitHub App webhook。

**做什么**
- `coderev serve`：一个极简 HTTP 服务（标准库 `http.server` 即可，先不引框架）
- 路由 `POST /webhook`：验签（HMAC-SHA256）→ 解析 `pull_request` 事件 → 调 `coderev pr`
- `GET /healthz` 返回 `{"status":"ok"}`
- 配置：`CODEREV_WEBHOOK_SECRET`、`CODEREV_REPOS`（白名单）

**验收**
- 用 `curl` 伪造签名错误的请求 → 401
- 签名正确 + 事件合法 → 触发一次审查
- 非白名单仓库 → 忽略并记日志

**涉及文件**：`src/coderev/server.py`（新）、`src/coderev/cli.py`、`tests/test_server.py`（新）
