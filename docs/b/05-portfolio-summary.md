# 多项目变更汇总

> **Excel 版**：[`assets/变更汇总-多项目模板.xlsx`](../assets/变更汇总-多项目模板.xlsx)
> **频率**：每两周一次（固定周一）。
> **方式**：人工从各项目台账"统计"页抄录，不在本表重复录明细。

---

## 1. 字段（19 列）

| # | 列名 | 来源 / 说明 |
|---|---|---|
| 1 | 项目代号 | |
| 2 | 项目名称 | |
| 3 | 客户 | |
| 4 | 统计区间 | 如 11.01–11.14 |
| 5 | 变更总数 | 台账统计页 |
| 6 | 澄清数 | 同上 |
| 7 | 新增 | 按变更类型 |
| 8 | 修改 | 按变更类型 |
| 9 | 删除 | 按变更类型 |
| 10 | L1 | 按最终等级 |
| 11 | L2 | 按最终等级 |

---

## 2. 合计行

- 第 5–17 列：直接求和。
- 第 18 列：**按变更总数加权**，不是简单平均（否则小项目会拉偏）。
  `Σ(项目平均用时 × 项目变更数) ÷ 变更总数`

---

## 3. 关键比率

| 指标 | 公式 | 红线 |
|---|---|---|
| 澄清占比 | 澄清数 ÷ 变更总数 | > 40%：需求沟通有问题 |
| 挂起占比 | 挂起数 ÷ 变更总数 | > 20%：客户确认拖住排期 |
| 超期未确认占比 | 超期数 ÷ 变更总数 | > 15%：客户确认流程失效 |
| 待升级占比 | 待升级数 ÷ 变更总数 | > 5%：需介入客户高层 |
| L3 占比 | L3 数 ÷ 变更总数 | > 15%：拆分或评审有问题 |

---

## 4. 三个容易加错的坑

1. **澄清计不计入**：计入总数，但工作量与报价记 0——否则"变更量"虚高。
2. **含税 / 不含税**：全公司统一不含税；混着加出来的总额没有意义。
3. **平均确认用时**：必须加权，不能简单平均。

---

## 5. 用途

- 管理层看全公司变更量与商务影响。
- 跨项目对比：哪个客户变更最多、哪个项目挂起最多。
- 销售/交付复盘：报价总额 vs 实际投入，判断是否需要调合同。
