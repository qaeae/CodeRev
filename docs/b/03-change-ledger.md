## 3. 自动计算列（公式口径）

| 列 | 公式逻辑 |
|---|---|
| 确认用时(天) | `IF(客户签字日期≠"", 签字日期 − 定级日期, "")` |
| 超期标记 | 已签字 → "已确认"；未签字且 `TODAY() > 确认截止日` → "超期未确认" |
| 挂起天数(天) | 未签字且已过截止日 → `TODAY() − 确认截止日` |
| 升级标记 | 挂起天数 ≥ 10 → "需升级" |

> 这四列不要手工填，填了会被公式覆盖。

## 4. 统计页（自动）

关键指标：

| 指标 | 口径 |
|---|---|
| 变更总数 | `COUNTA(编号)` |
| 澄清占比 | 澄清数 ÷ 变更总数 |
| L3 数量 | `COUNTIF(最终等级,"L3")` |
| 挂起数 | 状态 = 挂起（待客户确认） |
| 超期未确认 | `COUNTIF(超期标记,"超期未确认")` |
| 需升级 | `COUNTIF(升级标记,"需升级")` |
| 平均确认用时 | `AVERAGEIF(确认用时,">0")` |
| 平均挂起天数 | `AVERAGEIF(挂起天数,">0")` |

分布统计：变更类型、最终等级、排期影响、客户确认、状态。

## 6. 填写规则

- **8 分钟原则**：单条超过 8 分钟填不完，说明字段有问题，反馈而不是硬填。
- **一次变更的定义**：同一客户诉求、同一次沟通提出、同一个决策拍板 = 1 条；拆分实施在备注列子项，不另开单。
- **澄清也走单**：勾"澄清（无功能变化）"，跳过 D/E 段，产品经理确认即可。
- **报价不含税**：含税项目在备注单独说明。
- **超期自动挂起**：满 10 个工作日自动标"需升级"，由项目经理上报客户高层。
