## 附：示例周报

```
本周变更 7 条：新增 3 / 修改 3 / 澄清 1
定级分布：L1 4 · L2 2 · L3 1
挂起：2 条（超期未确认），其中 1 条挂满 10 天 → 已升级客户高层
报价：3 条需补充协议，合计 ¥18,000（不含税）
估算偏差：中位数 +38%（低估）
平均流转：提出 → 定级 4.2 天；定级 → 客户确认 5.8 天
会议：48 分钟（上周 65 分钟）
异常：CHG-1103 首次定 L2，会上改 L3（理由：涉及对账口径）
```

## 口径（固定，不许各写各的）

1. 变更总数按台账"编号"计数，一条变更一行。
2. 澄清计入总数，但工作量与报价记 0。
3. 报价一律不含税。
4. 确认用时 = 客户签字日期 − 定级日期。
5. 挂起 = 超期未确认；挂满 10 个工作日标记需升级。
